# Plan: Quality metrics, auto-adopted packs, and reduced doc density

## Context

Kilotemplate is structurally sound (87 validation checks pass) but has three gaps:

1. **No agent prompt quality metrics** — validate.mjs checks config/file consistency but never scores the quality of agent instructions themselves (clarity, scope, verification presence).
2. **Rule packs require manual activation** — packs sit in a separate `packs/` directory, inactive by default, with a validate.mjs warning nudging users to run the activation script. Friction for template adopters.
3. **Documentation density** — AGENTS.md (89 lines), ask.md (119 lines), README.md (128 lines), reviewer.md (60 lines). Some sections are verbose or templated — high cognitive load for onboarding. Every line in AGENTS.md costs tokens every session.

## Approach

**Area 1 — Deterministic prompt quality checks (no LLM calls)**: Add `checkAgentPromptQuality()` to validate.mjs. Inspects each agent file for structural quality markers — identity statement, scope boundaries, verification criteria, anti-hallucination language. Scores pass/warn on each dimension. No API calls, no non-determinism.

**Area 2 — Auto-adopt default packs, delete packs/ catalog**: Move the 3 default pack files to `.kilo/rules/` with `20-`/`21-`/`22-` prefixes. Add them to `kilo.jsonc` `instructions` array so they load automatically. Delete the `packs/` directory. Rewrite the activation script to manage rules directly in the rules directory (add from a source path, remove by name, list active) with kilo.jsonc instructions output. Remove the "no packs activated" warning from validate.mjs.

**Area 3 — Prune four files**: AGENTS.md (89→~55), README.md (128→~100), ask.md (119→~90), reviewer.md (60→~45). Preserve all functional content — just compress prose, merge sections, remove redundancy.

## Risks / Edge Cases

- **Deleting packs/ directory**: The activation script currently sources from packs/. After moving, the script must accept `--add <source-path>` (not pre-defined packs). Verifying the source file exists and has valid frontmatter before copying.
- **kilo.jsonc instruction array**: Adding paths manually is fragile — the script outputs the exact JSONC lines to paste. The `checkActivatedRules()` function verifies consistency, failing if a prefixed rule file exists but isn't in instructions.
- **validate.mjs line 478+ (checkRulesPacks)**: Rewriting this function must not break the `checkReadmeDirectoryTree()` function that follows (line 417+). The README tree no longer includes `packs/` so no impact expected.
- **Validation baseline**: Currently 87 checks pass. Expected after refactor: ~93-95 checks (existing 81 - 6 packs checks + ~8 new activated-rules checks + ~6-8 quality checks). The exact count will shift but must net to 0 failures.
- **AGENTS.md agent table validation**: `checkAgentsMdTable()` reads the agent table from the `## Agents` section. Our edits to other sections of AGENTS.md must not disturb the table format.
