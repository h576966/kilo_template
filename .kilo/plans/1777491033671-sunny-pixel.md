## Context

The `node tests/validate.mjs` anti-hallucination check flags 4 agents as warnings (⚠, not failures): ask, code, flash-patch, flash-debug. Three independent workstreams, all additive-only or subtractive-only edits. No config, schema, or test changes needed.

These files load every session, including plan agent (the expensive one):

1. **`00-conventions.md`** (46→38 lines): Remove "Tool Calls" section (model already knows to read schemas). Condense "Testing" section into a single bullet in "Do NOT". Save ~8 lines.

2. **`10-workflow.md`** (46→30 lines): Remove "Escalation Policy" section — now handled per-agent by Handoff sections in code/flash-patch/flash-debug, and by AGENTS.md "Do NOT" section. 3. **`AGENTS.md`** (60→48 lines): Remove "Maintaining AGENTS.md" section (meta — agents don't need instructions for maintaining their own instruction file). Remove "Skills" section (in README). Condense "Rules" explanation to 1 line. Save ~12 lines.

Total V4 Pro token savings: ~35 lines across files loaded every session, plus ~15 lines when ask agent is invoked.
